# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date :14.10.26

## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE
Open Autodesk Fusion 360 software and create a new design.
Select the XY plane and click on Create Sketch.
Draw the base plate using the Line and Arc tools
<img width="481" height="575" alt="Screenshot 2026-11-16 031522" src="https://github.com/user-attachments/assets/94342721-14d9-4372-b8f1-a7e69968909c" />
Create two circular holes at both ends of the base plate using the Circle tool.
Apply the required dimensions using the Dimension (D) tool.
Click on Finish Sketch and use the Extrude command to give thickness to the base plate.
<img width="381" height="107" alt="Screenshot 2026-11-16 031737" src="https://github.com/user-attachments/assets/8112423c-5512-45ad-b91f-7709794383fa" />
Apply the required dimensions and check all the features.
Save the completed 3D model
