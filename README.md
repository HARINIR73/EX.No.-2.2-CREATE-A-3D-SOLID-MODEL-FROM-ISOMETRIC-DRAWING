# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date :14.10.26

## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE
1. Sketch the base plate: Start a sketch on the bottom plane, draw a rectangle with rounded ends, and add two mounting circles.

2. ![Uploading Screenshot 2026-11-17 203411.png…]()

3. Extrude the base: Finish the sketch and Extrude the base plate profile upward to create the bottom flange with two holes.

4.<img width="437" height="522" alt="Screenshot 2026-11-17 215440" src="https://github.com/user-attachments/assets/2dbc91a8-7cf9-42d7-9de2-05cc7c6e7251" />

5.Create the vertical block: Start a new sketch on the top face of the base plate, draw a rectangle along the back edge, and Extrude it upward.

6. Sketch the upper arm: Create a sketch on the top face of the vertical block, extending a rectangular arm out toward the back.

7. <img width="431" height="542" alt="Screenshot 2026-11-17 221316" src="https://github.com/user-attachments/assets/54c7cea1-52d6-4bbb-a55d-5791c245dde8" />
 
8. Draw the top cylinder: At the end of the upper arm sketch, draw two concentric circles for the cylindrical boss and its center hole.

9.<img width="481" height="575" alt="Screenshot 2026-11-16 031522" src="https://github.com/user-attachments/assets/94342721-14d9-4372-b8f1-a7e69968909c" />

10. Extrude the upper arm: Finish the sketch and Extrude the rectangular arm and outer ring downward to match the top section thickness.

11. Extrude the raised boss: Use the same sketch to Extrude the outer ring upward to form the raised cylindrical collar.
  
12. Cut the through-hole: Ensure the inner circle of the cylinder cuts all the way through both the collar and the upper arm.
    
13. Create the support rib: Start a sketch on the center vertical plane, draw a right triangle connecting the vertical block to the base plate, and Extrude it symmetrically.
    
14. Verify the solid body: Confirm all features are set to Join so the bracket forms a single, unified 3D part.
